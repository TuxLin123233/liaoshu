# flybrain 能不能当"打字节奏"的随机源？

**结论先说：不能用来驱动逐字间隔，也不必用它做慢变量。它给出的起伏是白噪声。**

下面是本机实测数据，不是从文档抄的。跑实验的脚本在
`experiments/flybrain_slowvar.py`，复现方式见文末。

---

## 1. 先明确问题：打字节奏需要什么

打字节奏有两个时间尺度，对随机源的要求完全不同：

| 尺度 | 量级 | 需要什么 |
| --- | --- | --- |
| 逐字间隔 | 30–300 ms | 快速、廉价、**有自相关**（成串地冒字） |
| 心情起伏 | 10–120 s | **有记忆**：快了一阵子，之后慢慢慢下来 |

关键是"记忆"（自相关）。独立同分布的随机数在时间上是白的，打字看起来会像均匀的雨点。

---

## 2. 实测：flybrain 的信号在时间上有记忆吗

参数：`FlyBrain(data=..., device="cpu", sensory_input=False, seed=None)`，
1500 步（30 秒模拟时间），窗口 25 步 = 500 ms。

| 信号 | 每步放电 | 500ms 窗口 CV | **窗口 lag-1 自相关** |
| --- | --- | --- | --- |
| 总放电 | 7627.1 | 7.49% | **−0.046** |
| 下行神经元 L（656 个） | 15.0 | 10.82% | **+0.052** |
| 下行神经元 R（648 个） | 15.2 | 10.54% | **−0.117** |
| steer_L（1 个） | 0.0 | — | −0.094 |
| steer_R（1 个） | 0.0 | — | −0.093 |

**自相关全部 ≈ 0。** 也就是说：

- 起伏确实存在（CV 7.5%，峰谷差能到均值的 60%）
- 但它是**白噪声**：这一刻高，下一刻和它无关。窗口再长也平均不出慢变结构。
- `steer_L/R` 每组只有 1 个神经元（复现了文档里的坑 2），500ms 窗口均值是 0.0，读不出来。

### 对照：本地 OU 过程

`liaoshu/mood.py` 里 12 行代码生成的 AR(1) 过程，采样间隔 500ms：

| lag | 0.5 s | 2.5 s | 10 s | 30 s |
| --- | --- | --- | --- | --- |
| 自相关 | **0.979** | 0.899 | 0.617 | 0.209 |

这才叫"有记忆的心情"。同样时间尺度下 flybrain 是 −0.05。

## 3. 顺带实测的性能（这些反而是好消息）

| 项目 | 实测 |
| --- | --- |
| `FlyBrain(...)` 加载 | 1.25 s |
| 首次 `step()`（numba 编译） | 1.97 s |
| 稳态 `step()` | **7.96 ms/步**（要求 20 ms/步 → 2.5× 实时余量） |
| `step()` 期间 GIL | **释放**（纯 Python 线程推进速率比值 0.982） |

GIL 是释放的，所以果蝇大脑可以跑在后台线程里而不卡界面 —— 这一点和直觉相反，
也是为什么 `mood.py` 里用 `subprocess` 只是为了让 numba 编译和崩溃不牵连主进程，
不是被迫的。

## 4. 所以最终怎么设计

```
逐字间隔  ← 本地结构化模型（词内连打变快、标点必停、AR(1) 词组呼吸）
慢变量    ← 本地 OU 过程（相关时间 45 s，可以调出几十秒到几分钟的心情弧线）
flybrain  ← 可选，作为一个"岔路"实现出来，可以现场 A/B 对比
```

`liaoshu` 里三条路径都实现了，界面右上角「节奏源」可以随时切换：

- `本地 OU`：默认，秒开
- `果蝇`：flybrain 窗口化放电率 → 心情轨道（首次生成约 2 分钟并缓存到 `cache/`）
- `果蝇×本地`：两条轨道相乘

切到「果蝇」之后，状态栏会一直显示它**自己的实测统计量**，例如：

```
24/122 · 节奏源 果蝇 · CV 2.75% 自相关 -0.054 · 心情 ×1.04 · 速度 2.5×
```

这不是装饰。它让"这条轨道到底有多少信息"一直摆在眼前，省得自己骗自己。

### 如果你就是想要"16 万神经元在给我打字"

那也完全可以，`--mood fly` 就能跑通（数据在 `cache/fly_mood.txt`，轨道头里有生成时的
CV 和自相关）。只是要知道：**你付出的是一次 numba 编译、每分钟十几秒 CPU，
换来的是一个均价 1.0、无记忆的随机数**。它的浪漫价值大于信息量。

---

## 5. 复现

```bash
# 需要装了 flybrain 的 python
FLY_DATA=~/fly-data N_STEPS=1500 python -u experiments/flybrain_slowvar.py
```

生成一条可用的心情轨道（约 2 分钟，300 秒阅读时长）：

```bash
FLY_DATA=~/fly-data python tools/fly_mood.py \
  --seconds 300 --cache cache/fly_mood.txt
```
